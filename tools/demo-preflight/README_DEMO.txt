ShowDown 시연 안내
==================

[파일 위치] (패키지 폴더 = ShowDown.exe가 있는 폴더 기준)
- 게임 실행: ShowDown.exe
- 시연 전 점검: ShowDown\tools\demo-preflight\RunDemoCheck.bat
- 이 안내서: ShowDown\tools\demo-preflight\README_DEMO.txt
- AI 키: ShowDown\LLMKey.txt

[실행 전]
1. RunDemoCheck.bat 더블클릭 → 인터넷 / PC 시간 / 로그인 서버 / 멀티플레이 서버 / AI 키를 점검합니다.
2. 문제가 나오면 안내대로 처리합니다. 대부분은 휴대폰 핫스팟(또는 USB 테더링)으로 바꾸면 해결됩니다.

[실행]
- ShowDown.exe 실행.
- 계정이 있으면 ID/비밀번호로 로그인.
- 네트워크가 안 되거나 빠르게 시연하려면 LOGIN 옆 "오프라인으로 시작 (싱글플레이)".
  · 닉네임: GCC모범생, 코인 999,999 (상점에서 모든 캐릭터 구매/장착 가능)
  · 랭킹 / 멀티플레이 / 보상 저장은 오프라인에서 동작하지 않습니다.
- 싱글플레이 상대 캐릭터는 매 판 무작위로 나옵니다.

[로그인이 실패하면]
- 화면에 원인과 해결 방법이 표시됩니다.
  · 인터넷 연결 없음 → 랜선/와이파이 확인 또는 핫스팟
  · 와이파이 웹 인증 필요 → 브라우저로 인증하거나 핫스팟
  · PC 시간 틀림 → Windows 설정 > 시간 > '지금 동기화'
  · 로그인 서버 차단 → 핫스팟 또는 방화벽/백신에서 ShowDown 허용
- 그래도 안 되면 "오프라인으로 시작"을 누르세요.

[보스 AI 대화]
- ShowDown\LLMKey.txt 의 무료 Gemini 키를 사용합니다. (이 파일은 외부에 공유하지 마세요)
- 모델 순서: Gemma 4 26B(하루 14,400회) → Gemini 3.1 Flash Lite(하루 500회) → Gemini 3.5 Flash.
  게임이 분당/하루 한도를 직접 세어 넘지 않게 나눠 보냅니다.
- 구글 무료 서버가 붐비면(오류 500/503) 다른 모델로 바로 다시 보내고,
  모두 실패하면 미리 써 둔 대본 대사로 대답합니다. 게임은 멈추지 않습니다.
- 무료 한도는 매일 한국 시간 오후 4~5시쯤 초기화됩니다.
- 키가 없거나 인터넷이 없어도 보스는 대본 대사로 대답합니다.

[문제가 생기면]
- 로그 위치: ShowDown\Saved\Logs\ShowDown.log
